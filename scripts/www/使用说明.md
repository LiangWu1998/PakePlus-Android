# 物品小屋 v1.1：离线物品分类管理

适配目标：一加 13、安卓版 Edge，以及本次已经通过检测的本地 HTML 打开方式。此版本使用 HTML、CSS 和 JavaScript，在手机浏览器中独立运行；电脑不需要安装开发软件，手机不需要安装 Python，也不需要电脑开机或联网。

## 开始使用

1. 将 `离线物品管理.zip` 复制到手机并解压，或直接复制已经解压的“离线物品管理”文件夹。用 **Edge 打开其中的 `index.html`**，操作方式与检测页一致。不要在压缩包或聊天预览器内打开。
2. 点击“连接数据文件夹”，选择手机上自己建立的普通文件夹，例如 `Download/我的物品`，并允许读写。
3. 软件会在该目录下创建 `item-shelf-data`，正式数据与之前检测页的 `edge-probe-data` 相互独立。不要把测试照片当作正式物品数据。
4. 新建一个大分类，例如“衣服”；进入后新建小分类，例如“毛衣”；随后添加物品。
5. 每件物品必须有一张图片和一个标题；描述、存放位置可以留空。选择照片或拍照后，点击“保存物品”或“保存并继续”。
6. 等页面显示“已保存到文件夹”后再退出。进入“数据与设置 → 启动文件夹”，点击“记住当前文件夹”即可设为后续自动连接的目录。也可以直接点击“选择并记住”，选择已有目录或一个用于新清单的普通文件夹。

“先看看示例”使用临时内存数据，可以试用分类、编辑和搜索。示例模式有显眼提示，刷新后清空，不会写入正式文件。

## 记住启动文件夹

1. 打开“数据与设置”，在“启动文件夹”点击“选择并记住”，选中要长期使用的数据位置。已经连接清单时，也可以点“记住当前文件夹”，无需重新选择。
2. 出现“已记住”后，以后用同一浏览器打开同一个 `index.html`，页面会先读取启动设置并自动尝试连接。授权仍有效时，直接显示原分类和物品。
3. 如果浏览器要求重新授权，页面会显示“继续授权”。点击后授权原目录即可，不必再次在文件管理器中寻找目录。浏览器决定授权是否跨会话保留，网页不能保证永久免确认。
4. “选择并记住”可更换启动目录；普通“连接文件夹”只切换本次清单，不替换已设置的启动目录。“取消记住”只移除启动设置，不删除任何文件，也不中断当前已连接的清单。

启动设置使用浏览器的 IndexedDB 保存文件夹引用和清单标记；分类、物品和照片仍保存在实际数据文件夹中。启动时核对原清单标记，目录丢失、被替换或无法读取时停止自动连接，不另建空清单。

请保持浏览器和 `index.html` 的打开位置一致，升级时在原位置替换页面。无痕模式、清理浏览器数据、换浏览器、移动页面或系统为本地文件分配不同访问地址，可能使启动设置丢失，需要重新记住。若当前打开方式无法保存文件夹引用，界面会明确提示；本次手动连接和物品保存仍可使用。

## 首版功能

- 两级分类的新增、重命名和安全删除，分类名称可重复。
- 物品新增、查看、编辑、拍照和相册图片导入，单件物品一张图片。
- 修改所属小分类即可移动物品；可记录存放位置。
- 跨全部分类按标题连续关键词搜索；描述和存放位置不加入标题搜索。
- 按大分类、存放位置筛选，按新增时间、修改时间或标题排序。
- 物品先进入回收站，可恢复或确认后彻底删除记录。
- 完整文件夹备份、整库恢复、上一份记录恢复、未引用图片清理。
- 可设置启动文件夹，重开自动尝试连接，权限失效时在原引用上继续授权。

## 数据怎样保存

```text
你选择的文件夹/
└─ item-shelf-data/
   ├─ workspace.json       # 文件夹标记
   ├─ data.json            # 当前分类、物品、回收站记录
   ├─ data.previous.json   # 上一次保存前的记录
   ├─ images/              # 原图与列表缩略图
   └─ safety-backups/      # 从完整备份恢复前，保留的完整安全备份
```

照片保留清晰原图副本，不修改相册原图。支持单张不超过 40 MB 的 JPG、PNG、WebP、GIF、HEIC、HEIF、AVIF 或 BMP 图片。浏览器能解码时会生成最长边约 480 像素的 JPEG 缩略图；不能解码时仍可保存原文件，列表会提示点开查看或无法预览。浏览器无法预览的格式可在系统相册中转换后重新导入。

每次点击保存时，先写入并校验新图片，保留上一份元数据，再写入并读回当前元数据；确认完成才显示已保存。输入框内尚未点击保存的内容是草稿。取消编辑不会修改已保存记录。

请**只用一个页面编辑同一份数据**。软件会检查已保存版本是否被其他页面更新，但本地文件接口不提供跨多个页面、不同浏览器的完整数据库事务锁。

如果保存失败或权限过期，停止继续编辑，重新连接原文件夹后核对数据。主数据损坏时，如上一份记录可用，会只读打开上一份记录；点击“恢复上一份数据”后才写回，现有异常主数据会另存保留。不要手动编辑 JSON 文件来修复数据。

## 分类删除与回收站

- 大分类还有小分类时，不直接删除。
- 小分类还有物品时，不直接删除，**回收站中的物品也算在内**。可以先恢复并移动，或彻底删除，再删除空分类。
- 彻底删除的物品不能从回收站直接恢复，需要另有备份。
- 替换和删除后，部分图片可能仍被“上一份记录”引用；不会立即全部移除。需要释放空间时，在“数据与设置”执行“清理未引用图片”。清理只处理软件图片目录中，当前记录与上一份记录均未引用的、符合本软件命名规则的图片，不处理未知文件或完整备份目录。

## 完整备份与恢复

1. 进入“数据与设置”，点击“制作备份”，选择备份的存放位置。
2. 每次生成独立的 `物品备份-日期时间-编号` 文件夹，里面包含 `backup.json`、`data.json` 和 `images/`。全部文件复制并校验完成后才写入备份完成标记；不完整备份不能恢复。
3. **备份的单位是整个文件夹**。不要只复制 `data.json`。建议定期把完整备份复制到电脑或其他设备；只在同一部手机内留备份不能应对手机损坏。
4. 恢复时点击“选择备份”，选择具体的 `物品备份-…` 文件夹，输入“恢复”确认整库替换。首版不合并两个清单。
5. 恢复前会先在当前数据目录的 `safety-backups/` 中保留当前清单的完整备份。备份文件丢失、图片损坏、复制失败或存储不足时停止操作，不把未完成恢复标记为成功。

升级软件时可以替换 `index.html`，**不要覆盖或删除 `item-shelf-data`**。请保留数据文件夹及完整备份。

## 验证边界

之前的检测页已经由用户在一加 13／Edge 上确认了目录、文字、约 18.63 MB 照片写入及新页面读回。正式版沿用这条文件访问路线，但完整业务仍需在手机上按以下步骤验收：

- 断网建立大、小分类，分别用相册选图、拍照创建物品，标题空白时不允许保存，描述为空时允许保存。
- 创建两件同名物品，跨分类搜索并分别打开；搜索 `%`、`_` 时按普通字符处理。
- 编辑文字、替换图片、移动分类，关闭 Edge 后重新打开并连接原目录，核对结果。
- 删除相册原图后，软件中的导入副本仍能显示；回收和恢复不会影响其他物品。
- 制作完整备份，再恢复到另一个空数据目录，核对分类、物品、回收站和照片。
- 在设置中记住启动目录，关闭并重开同一 HTML，确认自动加载原数据；需要授权时点击“继续授权”，验证不再弹出目录选择器。
- 更换启动目录后重开核对目录；取消记住后重开不再自动连接，但原照片和记录仍在。

页面无联网接口、CDN、在线字体、账号、云端同步或统计脚本。浏览器本身的联网行为由浏览器设置控制，软件核心功能完全在本地执行。

## 电脑修改源码与重新构建

源码在另附的“物品管理源码”目录中。`构建.py` 使用 Python 3.7 及以上的标准库，将界面和逻辑打包成一个 HTML 和 ZIP。运行：

```bash
python 物品管理源码/构建.py
```

手机使用已经构建好的 `index.html`，不需要运行构建脚本。
